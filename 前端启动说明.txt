🔍 故障排查
========================================

如果前端依赖安装失败：
1. 确保网络连接正常
2. 尝试使用国内镜像：
   npm config set registry https://registry.npmmirror.com
3. 重新安装：
   cd frontend
   rm -rf node_modules
   npm install

如果端口被占用：
1. 查找占用进程：
   netstat -ano | findstr :5173
2. 终止进程：
   taskkill /PID <进程ID> /F
